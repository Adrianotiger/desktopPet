# Desktop Pet (eSheep)

Can you remember eSheep, the lovely desktop sheep? <img src='src/Images/esheep.png' />  
**If you had a lot of them on the desktop... welcome to this page!**  

This project gives you the possibility to add a pet to your desktop.  
[![eSheep for 64bit systems](https://img.youtube.com/vi/xN90p16tKGE/0.jpg)](https://www.youtube.com/watch?v=xN90p16tKGE) 

With a simple XML file (animations.xml) it is possible to change pet and animations.

# Application
This application is not a game, not a utility, and definitely not useful 😄. 
Its only purpose is to keep a little pet on your screen. 
The pet can fall down to the taskbar and detect windows on your desktop, allowing it to walk, run, and explore your workspace naturally, even across multiple monitors.

# Want to help?

## Create your own mate/pet
You can download the Editor and create your own Mate! Please contibute, uploading your work to the Pet-Folder.  
What you need:
- 1 application icon (or a png that will be converted to an icon)
- 1 animation image: an image with transparency with all possible positions. (.png not too big... Something like 1000x500 px)

For more info about editing the xml file and add your own pet, follow the <a href='../../wiki/'>Wiki</a> page.
