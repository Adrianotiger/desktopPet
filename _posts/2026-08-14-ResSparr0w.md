<h2>Minecraft pets</h2>

[RedSparr0w](https://github.com/RedSparr0w) used this tool:
<a href='https://nogard.dev/tools/minecraft-chibi-skin-maker'>https://nogard.dev/tools/minecraft-chibi-skin-maker</a>
to make some nice Minecraft mates (they are still available under Options).

As the spritesheet is always the same, an `animation.xml` template* can be used (they all have the same movements).

If you’d like to see more or leave [RedSparr0w](https://github.com/RedSparr0w) a comment, check out the [Pets page](https://adrianotiger.github.io/desktopPet/Pets/).
