# Jerma



NOTE: Jerma uses a giant spritesheet, so there will be a lag spike when you load him.



The titular spinning top, **Jerma985**, now in HD! He'll spin and skip around your computer, occasionally cheering you on as you write code, do homework, or do anything else you'd be distracted from.



This is my first Desktop Pet, so let's just say, it's quite experimental.



Feel free to suggest updates! He could certainly use some more emotes, so let me know if you find any similarly-style gifs/images. Same with voicelines!
